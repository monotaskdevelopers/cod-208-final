Project Description;
They are going to be beds, partying ( disco ball), instagram(doomscrolling) that makes the protagonist lose credits. Our protagonist is an average pixelated student( no need for gender). After the platforming section by opening a door you can get to the class. Joining the class allows a reaction based game to start which can give you 6 credits and each time you fail to push a key it lowers your credits by one. There will be easy 20 minimum credits, 26 minimum credits and 30 for hard difficulty. And after that level ends it shows how many credits they got. It will get harder as the game progresses. In 5 weeks/levels 30 credits. At the end there will be a diploma that shows you graduated. Game name is “The Last Semester”.
 
Technical and Theorical approach;
the visual design would be in a 2d space, with pixel art inspired environment and characters (like mario), the game environment would be setup in a horizontal manner where the user is moving to the right (forwards). As the game progresses, the speed increases and it gets harder for the character to avoid challenges as well as getting harder/faster assignments.
